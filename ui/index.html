LabGuide Studio Complete Help Guide & Recommendations

Everything you need to record smoothly, review drafts, edit steps/images, and manage saved workflows.

1. How to Use LabGuide Studio (Step-by-Step)
  1. Check System Readiness: Confirm the top-right status pills show Ollama Online (or plan to use Instant Draft + offline UIA fallback) and all Python packages ready.
  2. Configure Capture Studio: Enter your Guide Title, keep 3-Second Countdown and Instant Draft → Review First enabled, and click Start Recording.
  3. Perform Your Workflow: Switch to the target Windows 11 app during the 3-second countdown. Left-click UI controls normally and use shortcuts (Ctrl+S/C/V/Z/F). Press Ctrl+Alt+P to pause before typing passwords.
  4. Stop & Review: Press Ctrl+Alt+S (or click Stop & Review). You are taken straight to the Review & Step Editor tab.
  5. Prune, Blur, AI-Compile & Decide: Delete stray clicks, reorder steps, manually blur extra details, optionally click Run AI Descriptions on All Steps, then choose Save Workflow to Library or Discard Draft.
2. What Needs to Be Activated for Smooth Runs
  • Workspace Virtual Environment (.venv): Holds pynput, mss, Pillow, uiautomation, requests, rapidocr-onnxruntime, kokoro-onnx, soundfile, and pypdf on Python 3.11.
  • Local Ollama Service (localhost:11434): Required only if you want VLM-written natural language steps (gemma4:e4b or qwen2.5-vl:7b). Launching via the Desktop shortcut starts Ollama automatically; deterministic UIA fallback still works with zero errors if offline.
  • Per-Monitor V2 DPI Awareness: Handled automatically by labguide_engine.py and web_server.py via SetProcessDpiAwareness(2).
  • Administrator Mode (Only for Elevated Windows): Windows UIPI blocks non-admin hooks from capturing clicks inside elevated Admin windows (Registry Editor, Task Manager, Defender Firewall). Launch Studio from an elevated PowerShell when documenting those tools.
  • RX 6650 XT 8 GB VRAM Headroom: Keep at least 1,200 MB VRAM free before running large Ollama vision models. RapidOCR, Kokoro-82M TTS, and FFmpeg video rendering run strictly on CPU (0 MB VRAM).
3. Where Workflows Are Saved & File Structure
  • Staging Drafts (Pending Review): projects/labguide_studio/sessions/_staging/<timestamp>/
  • Saved Workflows Library (Approved): projects/labguide_studio/workflows/<timestamp_slug>/ (or directives/sops/ or knowledge/guides/ if selected).
  • Files Inside Every Workflow Folder:
    • guide.md — Portable Markdown SOP with relative ./assets/*.png images and collapsible full-screen context.
    • guide.html — 100% self-contained single-file dark-mode HTML guide (Base64 images embedded; safe to email or drop into SharePoint/Slack without broken links).
    • session.db — SQLite database storing step coordinates, UIA metadata, ISO controls, and edited text.
    • assets/step_XXX_crop.png & step_XXX_full.png — Annotated and redacted PNG screenshots.
    • assets/raw/step_XXX_raw.png — Untouched original capture so you can always click Reset from Raw.
4. How to Review & Edit Workflows (Built-In Studio + External Tools)

Built-In Step Editor (Best First Pass):

  • Edit any step's Title, Instruction, and Tip / Note directly and click Save Step (regenerates guide.md & guide.html instantly).
  • Click Move Up / Down or Delete Step to clean up misclicks (steps automatically renumber 1..N).
  • Click Manual Blur / Redact to drag rectangles over any missed sensitive text on cropped or full screenshots, or Reset from Raw to undo edits from the untouched raw PNG.
  • Click AI Rewrite Step on just one step, or Run AI Descriptions on All Steps once your step list is clean.

Recommended External Editors (Optional Polish):

  • Markdown & Docs: Open guide.md in Antigravity IDE / VS Code (live Markdown preview), Obsidian, or Typora.
  • Advanced Screenshot Markup (Arrows, Callouts, Step Numbers): Open assets/step_XXX_crop.png in ShareX Image Editor, Paint.NET, or Windows Snipping Tool, then click Update Title or Save Workflow to refresh guide.html.
  • Export to PDF: Open guide.html in Edge/Chrome and press Ctrl+P → Save as PDF.
5. Overlooked Options & Pro Recommendations
  • Self-Click Filtering & Floating Mini-HUD: LabGuide Studio automatically ignores clicks on LabGuide Studio and displays a compact always-on-top Mini-HUD (hidden from Windows 11 screen capture) so you always see your step count and Pause/Stop controls.
  • Password-Aware Typing Coalescer: Printable typing between clicks is buffered into a single Fill [Field] step—and UIA password fields or token/secret/key inputs automatically mask as •••••••• and blur the control rectangle.
  • Use "Instant Draft → Review First" + keep_alive="0": Prune accidental clicks before invoking Ollama, and keep keep_alive="0" enabled so your ~6.13 GB model unloads from RX 6650 XT VRAM right after compilation.
  • Multi-Format Exports: From Review or Saved Workflows, export HTML, Word .docx, PDF, SCORM 1.2 LMS .zip, Offline Bundle .zip, .srt captions, or a UIA-grounded replay.py automation script.
  • Watch Out for Windows UIPI (Admin Apps): If clicks inside Device Manager, Services, or Firewall stop logging, restart the Studio server from an Administrator terminal.
